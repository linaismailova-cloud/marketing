# Promo Group · Яндекс Директ

[Открыть публичный прототип](https://linaismailova-cloud.github.io/marketing/)

Сохранена последовательность первого варианта: предложение → тезис → тест и пять показателей → проблемы клиента → раскрывающиеся причины выбора → показатели бизнеса → кейсы → тарифы → сертификат и клиенты → отзывы → вопросы → обращение.

Первый экран, блок теста, кейсы, тарифы и отзывы используют оформление действующей посадочной. Кейсы сохранены целиком, с исходным порядком слайдов. Новые блоки используют ту же ширину, серые заголовки, оранжевые акценты, скругления и кнопки. В блоках причин выбора и вопросов работают раскрывающиеся пояснения. Сертификат и логотипы клиентов представлены компактно, как в первом варианте.

Заголовок начинается с «Приведем клиентов». Сразу за первым экраном расположен тезис «Продолжайте терять клиентов или работайте с нами». Показатели: 19 лет в интернет-маркетинге; 1500+ проектов выполнено; 250тыс+ заявок привели нашим клиентам; 10тыс+ настроенных рекламных кампаний; 85% клиентов с нами более 5 лет.

Кнопки заказа ведут к почте и телефону Promo Group. Изображения используются с действующего сайта. Если лицензионный Lab Grotesque не установлен на устройстве, применяется Onest. Этот шрифт уже используется в блоке теста исходной страницы.
