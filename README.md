# Promo Group · Яндекс Директ

[Открыть публичный прототип](https://linaismailova-cloud.github.io/marketing/)

Первый экран, тарифы, сертификаты, галереи кейсов, клиентов и отзывов собраны из блоков действующей страницы. Сохранены отдельные версии этих блоков для компьютера и телефона.

- Первый заголовок начинается с «Приведем клиентов». Сразу после первого экрана стоит тезис «Продолжайте терять клиентов или работайте с нами».
- В блоке о тесте указаны три этапа по дням и пять согласованных показателей.
- Причины выбора и ответы на вопросы раскрываются по клику. Подробности кейсов, сертификаты и рекомендательные письма можно открыть из галерей.
- Кнопки заказа ведут к почте и телефону Promo Group.

Изображения используются с действующего сайта. Публичный прототип использует Onest вместо лицензионного Lab Grotesque, если последний отсутствует на устройстве. Onest уже используется в блоке о тесте на исходной странице.
