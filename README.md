# Promo Group · Яндекс Директ

Публичный адаптивный прототип посадочной страницы. Откройте `index.html` в браузере. Материалы кейса, логотипы, сертификат и отзывы открываются с сайта Promo Group.

## Что предложено

| Блок | Зачем он нужен |
| --- | --- |
| Первый экран | Обещает понятный результат теста. Рядом с кнопкой указано, что 1 ₽ стоит работа агентства, а бюджет на рекламу оплачивается отдельно. |
| Тест | Показывает, что происходит на 1–3, 4–7 и 8–10-й дни. Три цифры дают представление об опыте агентства. |
| Проблемы и «Почему нас выбирают» | Взяли из соседних блоков Figma аргументы о закреплённой команде, опыте в разных нишах, аналитике до сделки и работе с посадочными. Каждый аргумент виден сразу. Пояснения и детали об AI раскрываются по клику. |
| Экономика и кейс | Связывают работу с продажами. У кейса «Мелодии сна» показаны заявки, цена заявки и изменение бюджета. |
| Тарифы | На одном экране видны цена, рекламный бюджет и KPI. Общие условия вынесены из карточек. |
| Сертификаты, клиенты, отзывы | Дают посмотреть документы и отзывы на сайте агентства. Год сертификата указан рядом с ним. |
| Вопросы и обращение | Детали раскрываются по запросу. Связаться с агентством можно по его публичной почте или телефону. |

Сохранены палитра Promo Group, тёплые плашки, оранжево-красные тарифы и отзывы, опубликованный кейс и условия теста. Пометка «до 13 октября» из макета требует подтверждения актуальности, поэтому её нет в тексте прототипа.
